# Code of Conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be professional and precise; argue about physics and code, not people.
Instances of unacceptable behavior may be reported to the maintainer at
joe.a.pecoraro@gmail.com, or via GitHub. Maintainers may remove, edit, or reject contributions and interactions
that violate this code.
